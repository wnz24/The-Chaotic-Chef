A learning project built with **Unity**, focused on understanding core game development concepts and workflows.

---

## 📖 Overview

This project was created as a **learning exercise in Unity**. The goal is to practice game development fundamentals such as player movement, physics, scene management, UI, and basic gameplay mechanics.

This is not a finished or commercial game — it is an evolving project used to experiment, learn, and improve Unity and C# skills.

---

## 🕹️ Features

- Player movement and controls  
- Basic gameplay mechanics  
- Scene loading and management  
- Simple UI elements (menus, HUD, etc.)  
- Prototype and experimental systems  

*Features may change as learning progresses.*
